# Анализ параметров Chen2020 на 1C оригинальных данных статьи
В данной директории проводится проверка работоспособности реализованных моделей DFN и DC1, а также анализ параметров алгоритмом Метрополиса. Здесь везде используется только экспериментальный профиль разряда 1C. 


### example.ipynb
Пример запуска моделей и проверка параметров Chen2020 на оригинальных экспериментальных данных.
- Результаты моделирования совпали с теми, что приводятся в оригинальной статье
- Показано, что при согласованном подборе параметров DC1 совпадает с DFN

### metropolis.ipynb
Алгоритм Метрополиса заключается в движении по пространству параметров случайными шагами. В случае, когда после очередного шага loss не превышает некоторого предела, шаг принимается и дальнейшее движение происходит из этой точки. Выполнены эксперименты только с DFN. Работа ведется только с параметрами D_s_anode, D_s_cathode, Fk_anode, Fk_cathode.
- Определим только один параметр - D_s_anode.
- Параметры Fk анода и катода сильно скоррелированы
