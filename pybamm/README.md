# Описание директорий
В каждой директории лежат экспериментальные данные (.data) с которыми проводятся сравнения модельных данных. Серьезные расчеты, состоящие из большого числа расчетов моделей с разными параметрами (например, более 100 расчетов) используют пул процессов и выполнены через py файлы. Более простые расчеты, а также построения графиков выполнены в ipynb файлах. Также в директориях лежат результаты расчетов в .data файлах.

### Chen2020_original
Используются данные по разряду 1C из оригинальной статьи ([Chen2020](https://iopscience.iop.org/article/10.1149/1945-7111/ab9050)).

### CellA_RPT0
Новая ячейка. Данные взяты из датасета ([Kirkaldi](https://zenodo.org/records/7235858))

# Структура репозитория
- Все экспериментальные данные приводятся к data файлам. Три столбца (время, напряжение, ток). csv файлы не используются и указаны в .gitignore
- Модели лежат в корне. Параметры из Chen2020 лежат в PARAMS.py
- В каждой директории добавляется одинаковый файл imports.py, позволяющий упростить работу с импортом моделей и параметров
- Все .py файлы необходимо запускать из директории, где лежит сам файл .py
- Описания экспериментов и выводы указаны в директориях
- Оригинальный датасет не идет в github.
